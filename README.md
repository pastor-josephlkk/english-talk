# Emma · 영어 선생님 챗봇 (3D 아바타)

API 키와 서버가 필요 없는 영어 회화 연습 챗봇입니다.
- AI: [WebLLM](https://github.com/mlc-ai/web-llm) — 사용자 브라우저 안에서 직접 실행
- 아바타: three.js + VRM(3D) — 표정·시선·말할 때 입 움직임·눈 깜빡임·숨쉬기
- 음성: 브라우저 내장 음성 읽기/듣기

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만듭니다 (예: `english-tutor`, Public).
2. 이 폴더의 **`index.html`, `avatar.vrm`, `README.md`** 를 업로드합니다. (`avatar.vrm`은 약 17MB)
3. 저장소 **Settings → Pages → Branch: main / (root)** 를 선택하고 Save.
4. 1~2분 뒤 `https://<내아이디>.github.io/english-tutor/` 주소가 생깁니다. 이 링크를 전달하세요.

## 아바타가 반응하는 때
| 상황 | 아바타 |
|---|---|
| 대기 중 | 편안한 표정, 가끔 눈 깜빡임, 숨쉬기 |
| 답을 기다리는 중 | 고개를 기울이고 시선을 돌려 생각하는 모습 |
| 맞는 문장을 썼을 때 | 활짝 웃음 |
| 이상한 문장·못 알아들었을 때 | 놀라고 당황한 표정, 고개를 갸웃 |
| 🎤 듣는 중 | 고개를 살짝 기울여 귀 기울임 |
| 말하는 중 | 입 모양(아·이·우·에·오)이 바뀌며 말함 |

## 내 아바타로 바꾸기
VRoid Studio에서 **VRM**으로 내보낸 파일(`.xwear`가 아님)을 `avatar.vrm`이라는 이름으로 덮어쓰면 됩니다.
